# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities to security@nhadesign.xyz

We will respond within 48 hours.

## Security Measures

- No sensitive data in repository
- All quotes scrubbed for secrets/API keys
- Static site deployment (no server-side vulnerabilities)
